# Governance

This document describes how the **credit-scoring-camunda** repository is maintained and how decisions are made. It applies to this open-source project on GitHub unless your organisation has adopted additional internal rules.

## Maintainer

- **Oleh Kondratow** ([GitHub: @OlehKondratow](https://github.com/OlehKondratow)) is the copyright holder listed in [LICENSE](LICENSE) and the primary maintainer for this repository.

Additional collaborators with **write** or **admin** access on GitHub are considered maintainers for the purpose of merging pull requests and enforcing community standards.

## Roles

| Role | Responsibility |
|------|----------------|
| **Maintainers** | Roadmap direction, releases and tags, branch protection, security and CoC enforcement, final merge decisions. |
| **Contributors** | Propose changes via pull requests; follow [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |

There is no separate elected committee; the maintainer(s) may invite trusted contributors to share maintenance duties.

## Decision-making

- **Day-to-day changes:** discussed in pull requests; maintainers approve and merge when requirements (tests, review policy) are met.
- **Larger direction:** discussed in issues or discussions; the maintainer makes the final call for this repository.
- **Security:** coordinated according to [SECURITY.md](SECURITY.md).

## Code of Conduct enforcement

For reporting and enforcement, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). **Community Moderators** for this project are the **maintainers** named above (and any GitHub collaborators explicitly designated as moderators in the future).

## Licensing

Contributions are accepted under the terms of the [LICENSE](LICENSE) (MIT), unless a pull request explicitly states otherwise and the maintainer agrees to an exception.
