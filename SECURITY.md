# Security

## Reporting a vulnerability

Please report security issues **privately** to the repository maintainers (e.g. GitHub Security Advisories for the repo, or your organisation’s security contact). Do not open a public issue for undisclosed vulnerabilities.

## Out of scope

General support questions belong in issues or discussions, not as security reports.

## Expectations

- Credit responses depend on maintainer availability.
- Follow coordinated disclosure where possible.
